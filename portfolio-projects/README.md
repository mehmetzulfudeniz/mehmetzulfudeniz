# Portfolio Projects

This directory contains job-focused engineering projects built to demonstrate practical implementation skills.

## 1. Support Diagnostic Toolkit

**Path:** [`support-diagnostic-toolkit/`](./support-diagnostic-toolkit)

Python CLI for DNS, TCP, HTTP, TLS and JSON API diagnostics. Designed around realistic first-line Support Engineer troubleshooting workflows.

## 2. Support Portal

**Path:** [`support-portal/`](./support-portal)

ASP.NET Core + SQLite ticket-management API demonstrating REST design, persistence, validation, and incident lifecycle concepts.

## 3. Android Support App

**Path:** [`android-support-app/`](./android-support-app)

Kotlin + Jetpack Compose Android utility for checking endpoint availability and latency with ViewModel/StateFlow state management.

## Why These Projects

The portfolio is intentionally organized around real job tasks rather than technology-only demo code:

- diagnose connectivity and service failures
- expose and consume HTTP services
- model support incidents
- persist operational data
- build modern Android UI/state flows
- document setup and engineering decisions clearly

Each project can be extracted into a standalone repository without changing its internal source layout.
